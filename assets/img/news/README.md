Images for news entries.

Drop a file here and reference it from a `_news/*.md` front matter as:

    thumbnail: assets/img/news/your-image.jpg

It renders as the right-hand thumbnail on /news/ and as a banner on the entry's
own page. Landscape crops around 800x500 work best. Entries without a thumbnail
render as text only, which is fine — the list handles a mix.
